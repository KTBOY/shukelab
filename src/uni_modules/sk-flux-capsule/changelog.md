# sk-flux-capsule 更新日志

## 1.1.0（2026-07-29）
- `height` 默认值由 `160` 调为 `120`，更贴合按钮比例
- `gloss` 默认值由 `true` 改为 `false`，降低多实例场景的合成开销
- 新增 `lazy` prop（默认 `true`）：基于视口观察器懒激活，进入视口附近才初始化 WebGL 与恢复渲染，离开视口自动暂停，显著改善多实例场景（如主题列表切到 ALL）的卡顿
- `resume` 增加视口可见性守卫；卸载时断开视口观察器

## 1.0.0（2026-08-01）
- 首次发布
- 基于 WebGL 域扭曲 FBM 着色器实现流体色彩胶囊效果
- 支持 H5 与微信小程序双端
- 支持 1~6 色调色板（单色自动派生明暗层次）
- 支持按压/搅动交互动力学
- 支持玻璃高光层、受控暂停、噪声种子等配置项
